# RTL source

This tree contains the complete approved public synthesizable RTL snapshot used by the portfolio preview. It includes the CPU, bus, SoC integration, project-owned peripherals, and authored vendor-IP integration boundaries.

Third-party-derived CPU and AES-GCM files retain their notices and licenses. Intel/Altera-generated memories, PLLs, ADC Platform Designer payload, complete Quartus projects, and simulator collateral are not redistributed.
